# Collagemaker fase 3 — delen — uitvoeringsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kinderen delen een collage rechtstreeks met een ander toestel via een code van 4 symbolen (PeerJS/WebRTC). Als het netwerk dat blokkeert, gaat de collage na toestemming via een eigen Cloudflare Worker (R2, 24 uur, eenmalig ophalen).

**Architecture:** Een nieuwe module `src/share/` met kleine, testbare delen: de symboolcode (`code.ts`), het pakket dat over de lijn gaat (`pakket.ts`, het bestaande `.collage`-zipbestand), het rechtstreekse kanaal (`peer.ts`, een dunne laag boven PeerJS met een injecteerbare fabriek zodat unit-tests zonder netwerk draaien), en de relay-client (`relay.ts`). De Worker (`worker/`) is één `fetch`-handler die in Node getest wordt met een nep-R2. De UI krijgt een Deel-dialoog in de editor en een Ontvang-dialoog op het startscherm; de toestemmingsregel (nooit / vragen aan kind / vragen aan leerkracht) is een leerkrachtinstelling. E2e-tests gebruiken een lokale PeerServer en een nagebootste relay.

**Tech Stack:** bestaand + `peerjs` (client), `peer` (lokale PeerServer, alleen voor e2e), `wrangler` en `@cloudflare/workers-types` (Worker).

**Spec:** `docs/superpowers/specs/2026-10-08-kids-collage-design.md` — fase 3 = sectie 12 punt 3; details in sectie 8 (delen), 7 (leerkracht: Cloudflare-instelling), 10 (fouten), 11 (testen).

## Global Constraints

- Alle constraints van fase 1 en 2 blijven: nooit emoji, Nederlands, knoppen minimaal 56 px, offline voor alles behalve delen, geen accounts.
- Code: 4 symbolen uit 12 (20.736 combinaties). PeerJS-id = `kidscollage-` + code in letters `a`–`l`. Bezet id → nieuwe code.
- Wat over de lijn gaat is het bestaande `.collage`-zipbestand (`naarBestand`). Ontvangen = `vanBestand` (validatie), openen als kopie (`kopieVan`) of alleen bekijken.
- Geen verbinding binnen 10 seconden → instelling "Cloudflare-delen": `nooit` → melding "Delen lukt niet op dit netwerk. Bewaar je collage als bestand."; `kind` → dialoog "Je netwerk blokkeert direct delen. Mag je collage via onze server gaan? Hij wordt na 24 uur gewist." Ja/Nee; `leerkracht` (standaard) → zelfde dialoog, bevestigen met de mastercode. Toestemming geldt voor één keer delen.
- Is er geen relay-adres ingesteld (`VITE_RELAY_URL` leeg), dan gedraagt de app zich als `nooit`.
- Worker: `PUT /relay/:code` (max 25 MB), `GET /relay/:code` (daarna gewist), vervalt 10 minuten na upload, R2-lifecycle wist alles na 24 uur, rate limit per IP, geen logging van inhoud, CORS alleen voor het app-domein (`TOEGESTANE_ORIGIN`).
- Klascode/verzamelmap (`/class/…`) en leerkracht-ontvangen horen bij fase 4, niet hier.
- Gebruik nooit `crypto.randomUUID` of `crypto.subtle`; willekeur via `crypto.getRandomValues`.
- Elk e2e-bestand importeert `test`/`expect` uit `e2e/helpers.ts`.

`src/share/code.ts`:
```ts
export const DEEL_SYMBOLEN = ['star', 'heart', 'cloud', 'drop', 'leaf', 'rocket', 'cake', 'car', 'pizza', 'tree', 'soccer-ball', 'paw-print'];
export const DEEL_LENGTE = 4;
const LETTERS = 'abcdefghijkl';

export function nieuweCode(): string[] {
  const r = crypto.getRandomValues(new Uint8Array(DEEL_LENGTE));
  return [...r].map((x) => DEEL_SYMBOLEN[x % DEEL_SYMBOLEN.length]);
}

export function codeNaarSleutel(code: string[]): string {
  if (code.length !== DEEL_LENGTE) throw new Error('Verkeerde codelengte');
  return code.map((s) => {
    const i = DEEL_SYMBOLEN.indexOf(s);
    if (i < 0) throw new Error(`Onbekend symbool: ${s}`);
    return LETTERS[i];
  }).join('');
}

export const peerId = (code: string[]): string => `kidscollage-${codeNaarSleutel(code)}`;
```

`src/share/pakket.ts`:

import JSZip from 'jszip';
import type { Collage } from '../document/types';
import { naarBestand } from '../storage/bestand';
import { DeelFout } from './fouten';

export { DeelFout };
export const MAX_PAKKET = 25 * 1024 * 1024;

export async function maakDeelpakket(c: Collage, assets: { blob(id: string): Blob | undefined }, voorbeeldPng: Blob): Promise<Blob> {
  const pakket = await naarBestand(c, assets, voorbeeldPng);
  if (pakket.size > MAX_PAKKET) throw new DeelFout('te-groot');
  return pakket;
}

export async function voorbeeldUitPakket(pakket: Blob): Promise<string | null> {
  try {
    const zip = await JSZip.loadAsync(pakket);
    const f = zip.file('voorbeeld.png');
    return f ? `data:image/png;base64,${await f.async('base64')}` : null;
  } catch {
    return null;
  }
}
```

  - `interface PeerLike { on(e: 'open', cb: (id: string) => void): void; on(e: 'connection', cb: (c: ConnLike) => void): void; on(e: 'error', cb: (err: { type?: string }) => void): void; connect(id: string, opts?: Record<string, unknown>): ConnLike; destroy(): void }`

  - `peerOpties(): Record<string, unknown>` — uit `VITE_PEER_HOST/PORT/PATH/SECURE` (leeg = PeerJS-standaard `0.peerjs.com`); in `MODE === 'e2e'` overschrijft `window.__peerOpties` dit

  - `startOntvanger(id: string, o: { onPakket(p: Blob): void; onFout?(f: DeelFout): void; fabriek?: PeerFabriek }): { klaar: Promise<void>; stop(): void }` — `klaar` faalt met `DeelFout('code-bezet')` bij `unavailable-id`, met `DeelFout('geen-verbinding')` bij netwerk/serverfout

import { describe, it, expect } from 'vitest';
import { startOntvanger, verstuurDirect, type ConnLike, type PeerFabriek, type PeerLike } from './peer';
import { DeelFout } from './fouten';

type H = Record<string, ((...a: any[]) => void)[]>;
function emitter() {
  const h: H = {};
  return { on(e: string, cb: (...a: any[]) => void) { (h[e] ??= []).push(cb); }, emit(e: string, ...a: any[]) { for (const cb of h[e] ?? []) cb(...a); } };
}

// Een kleine nep-"PeerServer": peers met een id kunnen elkaar bereiken.
function nepNet(opties: { serverWeg?: boolean; rtcGeblokkeerd?: boolean } = {}) {
  const peers = new Map<string, ReturnType<typeof maak>>();
  let teller = 0;
  function maak(id?: string) {
    const e = emitter();
    const echtId = id ?? `anon-${++teller}`;
    const peer = {
      ...e,
      id: echtId,
      connect(doel: string): ConnLike {
        const a = emitter(), b = emitter();
        const kantA: ConnLike = { on: a.on as any, send: (d) => setTimeout(() => b.emit('data', d)), close() {} };
        const kantB: ConnLike = { on: b.on as any, send: (d) => setTimeout(() => a.emit('data', d)), close() {} };
        setTimeout(() => {
          const ander = peers.get(doel);
          if (!ander) { peer.emit('error', { type: 'peer-unavailable' }); return; }
          if (opties.rtcGeblokkeerd) return; // verbinding komt nooit open
          ander.emit('connection', kantB);
          b.emit('open'); a.emit('open');
        });
        return kantA;
      },
      destroy() { peers.delete(echtId); },
    };
    setTimeout(() => {
      if (opties.serverWeg) { peer.emit('error', { type: 'network' }); return; }
      if (id && peers.has(id)) { peer.emit('error', { type: 'unavailable-id' }); return; }
      peers.set(echtId, peer);
      peer.emit('open', echtId);
    });
    return peer;
  }
  const fabriek: PeerFabriek = (id) => maak(id) as unknown as PeerLike;
  return { fabriek, peers };
}

const pakket = () => new Blob([new Uint8Array([1, 2, 3, 4])]);

export interface ConnLike {
  on(e: 'open' | 'close', cb: () => void): void;
  on(e: 'data', cb: (d: unknown) => void): void;
  on(e: 'error', cb: (err: unknown) => void): void;

  close(): void;

export interface PeerLike {
  on(e: 'open', cb: (id: string) => void): void;
  on(e: 'connection', cb: (c: ConnLike) => void): void;
  on(e: 'error', cb: (err: { type?: string }) => void): void;
  connect(id: string, opts?: Record<string, unknown>): ConnLike;
  destroy(): void;
}
export type PeerFabriek = (id?: string) => PeerLike;

type E2eVenster = { __peerOpties?: Record<string, unknown>; __deelTimeoutMs?: number };

export function peerOpties(): Record<string, unknown> {
  if (import.meta.env.MODE === 'e2e') {
    const o = (window as unknown as E2eVenster).__peerOpties;
    if (o) return o;
  }
  const env = import.meta.env;
  const o: Record<string, unknown> = { debug: 0 };
  if (env.VITE_PEER_HOST) o.host = env.VITE_PEER_HOST;
  if (env.VITE_PEER_PORT) o.port = Number(env.VITE_PEER_PORT);
  if (env.VITE_PEER_PATH) o.path = env.VITE_PEER_PATH;
  if (env.VITE_PEER_SECURE) o.secure = env.VITE_PEER_SECURE === 'true';
  return o;
}

export function deelTimeout(): number {
  if (import.meta.env.MODE === 'e2e') {
    const t = (window as unknown as E2eVenster).__deelTimeoutMs;
    if (typeof t === 'number') return t;
  }
  return 10_000;
}

export const standaardFabriek: PeerFabriek = (id) =>
  (id ? new Peer(id, peerOpties()) : new Peer(peerOpties())) as unknown as PeerLike;

const isNetwerkFout = (t?: string) => t === 'network' || t === 'server-error' || t === 'socket-error' || t === 'socket-closed' || t === 'disconnected' || t === 'webrtc' || t === 'browser-incompatible';

export function verstuurDirect(doelId: string, pakket: Blob, o: { timeoutMs?: number; fabriek?: PeerFabriek } = {}): Promise<void> {
  const fabriek = o.fabriek ?? standaardFabriek;
  return new Promise<void>((resolve, reject) => {
    let klaar = false;
    const peer = fabriek();
    const einde = (f?: DeelFout) => {
      if (klaar) return;
      klaar = true;
      clearTimeout(timer);
      try { peer.destroy(); } catch { /* al weg */ }
      if (f) reject(f); else resolve();
    };
    const timer = setTimeout(() => einde(new DeelFout('geen-verbinding')), o.timeoutMs ?? deelTimeout());
    peer.on('error', (err) => {
      if (err?.type === 'peer-unavailable') einde(new DeelFout('niet-gevonden'));
      else if (isNetwerkFout(err?.type)) einde(new DeelFout('geen-verbinding'));
    });
    peer.on('open', async () => {
      const bestand = await pakket.arrayBuffer();
      const conn = peer.connect(doelId, { reliable: true, serialization: 'binary' });
      conn.on('open', () => conn.send({ soort: 'collage', bestand }));
      conn.on('data', (d) => { if ((d as { soort?: string })?.soort === 'ontvangen') einde(); });
      conn.on('error', () => einde(new DeelFout('geen-verbinding')));
    });
  });
}

export function startOntvanger(id: string, o: { onPakket(p: Blob): void; onFout?(f: DeelFout): void; fabriek?: PeerFabriek }): { klaar: Promise<void>; stop(): void } {
  const peer = (o.fabriek ?? standaardFabriek)(id);
  let geopend = false;
  const klaar = new Promise<void>((resolve, reject) => {
    peer.on('open', () => { geopend = true; resolve(); });
    peer.on('error', (err) => {
      const f = err?.type === 'unavailable-id' ? new DeelFout('code-bezet') : isNetwerkFout(err?.type) ? new DeelFout('geen-verbinding') : null;
      if (!f) return;
      if (!geopend) reject(f);
      else o.onFout?.(f);
    });
  });
  peer.on('connection', (conn) => {
    conn.on('data', (d) => {
      const bericht = d as { soort?: string; bestand?: ArrayBuffer | Uint8Array };
      if (bericht?.soort !== 'collage' || !bericht.bestand) return;
      o.onPakket(new Blob([bericht.bestand as ArrayBuffer]));
      conn.send({ soort: 'ontvangen' });
    });
  });
  return { klaar, stop: () => { try { peer.destroy(); } catch { /* al weg */ } } };
}

import { DeelFout } from './fouten';

export function relayAdres(): string | null {
  const a = import.meta.env.VITE_RELAY_URL;
  return a ? a.replace(/\/+$/, '') : null;
}

export function maakRelay(adres: string | null) {
  const basis = adres ? adres.replace(/\/+$/, '') : null;
  return {
    ingesteld: basis !== null,
    async upload(sleutel: string, pakket: Blob, f: typeof fetch = fetch): Promise<void> {
      if (!basis) throw new DeelFout('geen-verbinding');
      let r: Response;
      try { r = await f(`${basis}/relay/${sleutel}`, { method: 'PUT', body: pakket }); } catch { throw new DeelFout('relay'); }
      if (r.status === 413) throw new DeelFout('te-groot');
      if (!r.ok) throw new DeelFout('relay');
    },
    async download(sleutel: string, f: typeof fetch = fetch): Promise<Blob | null> {
      if (!basis) return null;
      try {
        const r = await f(`${basis}/relay/${sleutel}`, { method: 'GET' });
        return r.ok ? await r.blob() : null;
      } catch {
        return null;
      }
    },
  };
}

export const relay = () => maakRelay(relayAdres());

export interface R2BucketLike {
  put(key: string, body: ArrayBuffer, o?: { customMetadata?: Record<string, string> }): Promise<unknown>;
  get(key: string): Promise<{ customMetadata?: Record<string, string>; arrayBuffer(): Promise<ArrayBuffer> } | null>;
  delete(key: string): Promise<void>;
}
export interface Env {
  BAK: R2BucketLike;
  TOEGESTANE_ORIGIN: string;
  LIMIET?: { limit(o: { key: string }): Promise<{ success: boolean }> };
}

const MAX = 25 * 1024 * 1024;
const GELDIG_MS = 10 * 60_000;
const SLEUTEL = /^[a-l]{4}$/;

export async function verwerk(req: Request, env: Env, nu = Date.now()): Promise<Response> {
  const cors: Record<string, string> = {
    'Access-Control-Allow-Origin': env.TOEGESTANE_ORIGIN,
    'Access-Control-Allow-Methods': 'GET, PUT, OPTIONS',
    'Access-Control-Allow-Headers': 'Content-Type',
    Vary: 'Origin',
  };
  const antwoord = (status: number, body: BodyInit | null = null, extra: Record<string, string> = {}) => new Response(body, { status, headers: { ...cors, ...extra } });
  if (req.method === 'OPTIONS') return antwoord(204);
  const m = new URL(req.url).pathname.match(/^\/relay\/([^/]+)$/);
  if (!m || !SLEUTEL.test(m[1])) return antwoord(404);
  if (env.LIMIET) {
    const ip = req.headers.get('CF-Connecting-IP') ?? 'onbekend';
    if (!(await env.LIMIET.limit({ key: ip })).success) return antwoord(429);
  }
  const sleutel = `relay/${m[1]}`;
  if (req.method === 'PUT') {
    const lengte = Number(req.headers.get('Content-Length') ?? '0');
    if (lengte > MAX) return antwoord(413);
    const body = await req.arrayBuffer();
    if (body.byteLength > MAX) return antwoord(413);
    await env.BAK.put(sleutel, body, { customMetadata: { tijd: String(nu) } });
    return antwoord(201);
  }
  if (req.method === 'GET') {
    const obj = await env.BAK.get(sleutel);
    if (!obj) return antwoord(404);
    const tijd = Number(obj.customMetadata?.tijd);
    if (!Number.isFinite(tijd) || nu - tijd > GELDIG_MS) { await env.BAK.delete(sleutel); return antwoord(404); }
    const data = await obj.arrayBuffer();
    await env.BAK.delete(sleutel);
    return antwoord(200, data, { 'Content-Type': 'application/octet-stream', 'Cache-Control': 'no-store' });
  }
  return antwoord(405);
}

export default { fetch: (req: Request, env: Env): Promise<Response> => verwerk(req, env) };

import type { CloudDelen } from '../storage/instellingen';
import { codeNaarSleutel, peerId } from './code';
import { DeelFout } from './fouten';
import { verstuurDirect } from './peer';

export type Toestemming = (soort: 'kind' | 'leerkracht') => Promise<boolean>;

export async function deel(o: {

  direct?: (doelId: string, pakket: Blob) => Promise<void>; relay?: ReturnType<typeof maakRelay>;
}): Promise<'direct' | 'server'> {
  const direct = o.direct ?? ((id: string, p: Blob) => verstuurDirect(id, p));
  try {
    await direct(peerId(o.code), o.pakket);
    return 'direct';
  } catch (e) {
    if (!(e instanceof DeelFout) || e.code !== 'geen-verbinding') throw e;
  }
  const relay = o.relay ?? standaardRelay();
  if (o.instelling === 'nooit' || !relay.ingesteld) throw new DeelFout('geen-verbinding');
  if (!(await o.vraag(o.instelling))) throw new DeelFout('geweigerd');
  await relay.upload(codeNaarSleutel(o.code), o.pakket);
  return 'server';
}
```

// Nagebootste relay: beide toestellen delen dezelfde opslag in het testproces.
export async function nepRelay(pages: Page[]): Promise<Map<string, Buffer>> {
  const opslag = new Map<string, Buffer>();
  for (const p of pages) {
    await p.route('**/__relay/relay/*', async (route) => {
      const sleutel = route.request().url().split('/').pop()!;
      if (route.request().method() === 'PUT') { opslag.set(sleutel, route.request().postDataBuffer() ?? Buffer.alloc(0)); await route.fulfill({ status: 201 }); return; }
      const d = opslag.get(sleutel);
      if (!d) { await route.fulfill({ status: 404 }); return; }
      opslag.delete(sleutel);
      await route.fulfill({ status: 200, body: d, contentType: 'application/octet-stream' });
    });
  }
  return opslag;
}

# Delen via de server klaarzetten (Cloudflare)

Rechtstreeks delen werkt zonder eigen server (via de publieke PeerJS-server). De eigen relay is alleen nodig voor netwerken die WebRTC blokkeren.

1. Log in: `npx wrangler login`
2. Maak de opslag: `npx wrangler r2 bucket create collagemaker-relay`
3. Laat alles na 1 dag wissen: `npx wrangler r2 bucket lifecycle add collagemaker-relay verval-na-1-dag --expire-days 1`
   (of in het Cloudflare-dashboard: R2 → collagemaker-relay → Settings → Object lifecycle rules)
4. Zet in `worker/wrangler.toml` bij `TOEGESTANE_ORIGIN` het adres van de app (bijvoorbeeld `https://collagemaker.pages.dev`).
5. Zet de Worker online: `npm run relay:deploy`. Noteer het adres (bijvoorbeeld `https://collagemaker-relay.<jouw-naam>.workers.dev`).
6. Maak in de projectmap een bestand `.env.production` met `VITE_RELAY_URL=<dat adres>` en bouw de app opnieuw (`npm run build`).
7. Kies in het leerkrachtmenu de regel voor delen via de server (standaard: "Mij vragen").

De Worker logt geen inhoud. Een pakket kan één keer opgehaald worden, vervalt na 10 minuten en wordt na 24 uur in elk geval gewist.
